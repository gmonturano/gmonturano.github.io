Software

Code, replication materials, statistical workflows and research tools.

This page collects the main programming environments and computational tools that support my research activity. My work combines empirical economics, econometrics, data science and reproducible research workflows.

The corresponding code is primarily developed in R, Python and LaTeX, and the associated materials — including replication files, scripts, templates and project repositories — are organized and shared through GitHub.

The repositories include both general-purpose tools and project-based materials for data analysis, policy evaluation, spatial methods, machine learning applications and academic writing.

R

Statistical computing, econometrics and reproducible analysis

R is my main environment for statistical modelling, empirical analysis and reproducible research. I use it extensively both for applied economic research and for data-intensive statistical workflows.

  • Data cleaning, manipulation and transformation.
  • Descriptive statistics and exploratory data analysis.
  • Econometrics, causal inference and policy evaluation.
  • Spatial econometrics and territorial data analysis.
  • Statistical graphics, research outputs and reproducible reports.

Python

Machine learning, networks and computational methods

Python is used for computational tasks that complement my empirical research, especially when flexible automation and scalable analysis pipelines are required.

  • Machine learning and predictive modelling.
  • Network analysis and graph-based methods.
  • Web scraping and automated data collection.
  • Text analysis and computational processing of unstructured data.
  • Custom scripts for research pipelines and data integration.

LaTeX

Academic writing, manuscripts and research templates

LaTeX supports the preparation of manuscripts, academic CVs, reports, slides and other professional materials. It is part of my standard workflow for research dissemination and document production.

  • Journal articles, working papers and project reports.
  • Curriculum vitae, academic templates and formal documents.
  • Slides, handouts and conference material.
  • Integrated workflows connecting code output and manuscript preparation.

Repository structure and research workflow

In practical terms, the software side of my work is organized around a small set of complementary repository types.

  • Replication repositories for papers, with scripts, output tables, figures and documentation.
  • R projects for statistical analysis, econometric estimation, data manipulation and spatial methods.
  • Python projects for machine learning, network analysis, scraping and text analysis.
  • LaTeX repositories for manuscripts, templates, slides and academic documents.
